贡献方式

How to Contribute

Fork、测试、PR。

Fork, test, PR.

1. Fork & 分支

1. Fork & branch

从主仓库 fork 一份，创建明确命名的 feature 分支。

Fork the repo and create a clearly named feature branch.

2. 跑测试

2. Run tests

提交前先确认前端、Rust 与关键路径测试都通过。

Make sure frontend, Rust, and key path tests pass before you submit.

3. 提交 PR

3. Open a PR

说明变更背景、影响范围、测试结果和后续建议。

Describe the rationale, scope, test results, and follow-up suggestions.
